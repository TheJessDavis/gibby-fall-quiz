# Build Your Fall Schedule

An interactive quiz that matches people to real Fall 2026 workshops at The Everett (The Gibby).
Five quick questions, then a shortlist of classes worth signing up for.

Self-contained single-file app: `index.html` (no build step, no dependencies).

## Hosting on GitHub Pages
1. Push this folder to a GitHub repo.
2. Repo **Settings > Pages** > Source: **Deploy from a branch** > Branch: **main** / **/ (root)** > Save.
3. Live in ~1 minute at `https://<your-username>.github.io/gibby-fall-quiz/`.
